## 版本一（中文字 186）

说话就能办业务的银行智能体。用户用自然语言发起转账、分析账单、管理订阅与卡片，
Agent 自主识别意图、规划任务，并在严格的权限框架内执行。

核心理念是：Agent 可以表达意图，但不能给自己发权限。风险分级由代码判定而非模型决定，
自然语言只作为数据进入解析器，提示注入无法提权；确认凭证绑定操作内容哈希，
篡改参数立即失效；每次执行前重算风险等级。

技术上采用两阶段执行、受限 AST 白名单沙箱、哈希链防篡改审计与异常熔断，
并自建带双重记账和幂等约束的模拟银行核心。
